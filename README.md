# DSE USB Link — ดาวน์โหลด

ใช้คอนโทรล Deep Sea Electronics (DSE) ที่เสียบกับมือถือ Android จากคอม Windows ผ่าน Wi-Fi / Tailscale / ฮอตสปอต

ดาวน์โหลดได้ที่ [Releases](https://github.com/totza2010/dse-usb-link-releases/releases/latest)

| ไฟล์ | ใช้กับ |
|---|---|
| `DseUsbLink-X.Y.Z.apk` | มือถือ Android 9 ขึ้นไป |
| `DseUsbLink-Setup-X.Y.Z.exe` | คอม Windows 10/11 x64 (ลงไดรเวอร์ usbip-win2 ให้ถ้ายังไม่มี) |
| `SHA256SUMS.txt` | ค่า SHA-256 ของไฟล์ทั้งหมด (แอปและโปรแกรมใช้ตรวจตอนอัพเดท) |

แอปและโปรแกรมตรวจหาเวอร์ชันใหม่จากที่นี่เอง

ไดรเวอร์ USB/IP: [usbip-win2](https://github.com/vadimgrn/usbip-win2) (BSD-2-Clause) โดย Vadym Hrynchyshyn
